📘 Structured Query Language (SQL)
Універсальна мова для роботи з реляційними базами даних

Історія та стандарти

SQL розроблено в IBM у 1970-х (спочатку SEQUEL). Стандартизовано ANSI/ISO з 1986 року. Остання версія — SQL:2023 з підтримкою JSON та графових запитів (SQL/PGQ).

SQL-86 SQL-92 SQL:1999 SQL:2003 SQL:2011 SQL:2016 SQL:2023

Основні команди

  • SELECT — вибірка даних
  • INSERT — додавання записів
  • UPDATE — оновлення даних
  • DELETE — видалення записів
  • CREATE/ALTER/DROP — DDL-операції
  • JOIN — об'єднання таблиць
  • GROUP BY / HAVING — агрегація
  • WITH (CTE) — спільні табличні вирази

Сучасні можливості

  • Window Functions — аналітичні функції (ROW_NUMBER, RANK, LAG)
  • JSON / XML — робота з напівструктурованими даними
  • Recursive CTE — рекурсивні запити для ієрархій
  • Temporal Tables — часові таблиці (SQL:2011)
  • Row Pattern Matching — розпізнавання шаблонів (SQL:2016)
  • Polymorphic Table Functions — поліморфні функції

Популярні діалекти

  • T-SQL — Microsoft SQL Server / Sybase
  • PL/SQL — Oracle Database
  • PL/pgSQL — PostgreSQL
  • MySQL SQL — MySQL / MariaDB
  • SQLite SQL — легковаговий діалект
  • N1QL / SQL++ — Couchbase (для JSON)
  • PartiQL — DynamoDB (SQL-подібний)
  • Cypher / GQL — графові бази (Neo4j)
